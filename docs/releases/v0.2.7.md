# V0.2.7 · 时间轴动效与 Windows 自带环境便携版

- 网页时间轴逐行错峰展开。筛选淡出、收藏置顶、完成撤销、个人计划保存和专注时间轴都有对应的视觉反馈。
- 长按时间条在组内拖动排序，或使用 `Alt` 加上下方向键。调整后自动保存，可以撤销，活动日期保持原位。
- 从提醒收件箱可定位到时间轴活动。详情即时打开和关闭，继续显示活动头图。
- NIKKE 优先保存活动时间和列表头图，再读取公告正文。正文失败时保留已获取的图片与活动。

## 下载与升级

在 [GitHub Release](https://github.com/woodrice/acg-calendar/releases/tag/V0.2.7) 下载 `Playtime-V0.2.7-standalone-windows-x64.zip`。可用同名 `.sha256` 附件核验文件。完整解压到新目录，进入 `Playtime`，双击 `Playtime.exe`。包内置 Python、IANA 时区数据和 .NET 桌面运行时。五款日历随包提供，其中 NIKKE 国际服、碧蓝航线国服和绝区零国服以预装插件提供。

升级前，从托盘退出旧版并备份原目录的整个 `data/`。将旧数据迁移到新目录的 `data/`，保留个人数据库、窗口设置与自定义插件。按需更新公开插件，避免覆盖自定义文件。详见 [Windows 自带环境便携版](../windows-standalone.md)。
