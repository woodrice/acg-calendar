# V0.3.26 · 安卓工具链与测试维护

日期：2026-11-14。本版合并 PR #2、#3，是 v0.3.25 的维护补丁。插件 API 1、活动 ID、个人标记、计划和数据格式保持兼容，日历功能和采集规则不变。

## 本版变化

- 配套升级 Android AGP 9.5.1、Gradle 9.9.1、Build Tools 36.0.0；JDK 17、Chaquopy 17.2.0、compileSdk/targetSdk 35 保持。
- Wrapper JAR 与下载 ZIP 继续验证官方 SHA256，README 补齐工具链联动要求。
- Playwright 开发依赖升级至 1.65.0；应用前端仍不需要 npm 构建或线上 AI。
- Node 端网页回归请求在检查状态后读完正文，避免未消费响应留至服务器关闭。原 Linux Node/Undici 内部断言的精确上游根因未独立复现，不承诺所有环境中永不出现。

## 验证范围

修复 PR #2、#4 的各 11 项 CI 已通过，包含 Python/系统矩阵、桌面编译、安卓双 ABI 构建及 ARM64 lint、Edge/Chromium 各 13 项网页回归。正式发布提交的 CI 以 [Actions](https://github.com/woodrice/acg-calendar/actions) 为准。

安卓仍有面向未来 AGP 10 / Gradle 10 的弃用迁移提示。本次只验证固定版本，不宣称未来大版本兼容。APK 继续采用本机既有调试密钥，新的真机、系统栏和软键盘验收待完成。

## 升级

1. 从旧版托盘选择“退出游时”，在设置中创建备份，并另存整个旧 `data/`。
2. 新版完整解压到新目录，再迁移旧数据，保留数据库、窗口设置和自定义插件；不要用新包的初始文件覆盖旧数据。
3. 运行新版，核对个人标记、计划、游戏组合及提醒范围。手动同步仍遵守来源冷却和限流。

Android 覆盖安装要求签名一致；若签名不一致，不要为升级直接卸载有个人数据的旧版。测试版导出尚不完整，应先确认可保留数据再处理。卸载/清除应用数据会删除个人记录。

## 已知边界

- 普通网页/Windows 服务只监听本机，信任当前系统用户；读 API 没有独立登录，不可公开代理到公网。见 [SECURITY](../../SECURITY.md)。
- 计划删除的完整恢复 ID/关联契约仍待实现；安卓重新创建式撤销不是完整恢复保证。
- APK 为调试测试包，不是应用商店正式签名包；新构建的真机、软键盘、低版本 WebView 和系统栏验证仍待完成。历史模拟器结果不等于新版本真机验收。
- 原生桌面通知需要程序运行；Windows 时钟面板由系统管理，本项目不直接注入其日历。
- 公开资料可能因源站和网络延迟缺失；活动情况及时间以游戏官方为准。
