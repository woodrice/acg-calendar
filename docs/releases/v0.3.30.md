# V0.3.30 · 头图时间轴与截止时间修复

日期：2026-11-14。本版接续 v0.3.26，插件 API 1、活动 ID、个人标记、计划和数据格式保持兼容。

## 本版变化

- 网页工具栏提供“简洁时间轴 / 自适应头图 / 固定宽度头图”。头图保持原始比例、优先显示上方 1/3，右缘渐隐；自适应兼顾长条覆盖与短条防留空。固定模式保留完整日期轴 2/3 的图宽，短活动只裁切图片。选择只保存在当前浏览器，不改变活动起止时间或桌面气泡布局。
- 修正明日方舟单独寻访公告中“寻访数据契约交换所”的识别，卡池与交换所分别计时。以“将雪投火”为例：卡池北京时间 **11 月 15 日 03:59** 结束；交换所北京时间 **11 月 18 日 03:59** 结束，不再延长抽卡期限。[官方公告](https://ak.hypergryph.com/news/4916)
- 旧卡池记录成功重新读取公告后按原 ID 纠正日期，保留收藏、备注和关联计划；个人手动时间校正继续优先，不静默清除。
- README 开头及独立 [DISCLAIMER.md](../../DISCLAIMER.md) 明确数据、提醒与责任边界。网页页头及专注时间轴有声明入口，Windows 侧栏底部提供离线弹窗，移动端“我的 → 关于与来源”直接显示说明。源码 MIT 与第三方许可分别适用。
- 发布资源预检包含链接到的本机 HTML 页面；将头图与官方卡池回归纳入默认网页测试。

## 本机验证

- 337 项 Python 后端测试通过。
- Edge 下 15 组离线网页回归通过，涵盖头图比例、短条、渐隐、亮暗与窄屏、活动日期与来源、个人计划、拖动、筛选、可访问性及手机外壳。
- Windows x64 自带环境程序重新编译；ARM64 与 x86_64 Android 调试包重新构建，ARM64 lint 通过。
- 声明页单独检查本机路由、CSP、普通及专注入口、亮暗主题和 375px 宽度。测试使用隔离目录，不读取个人 `data/` 或反复联网同步。

远端 CI 结果以 [Actions](https://github.com/woodrice/acg-calendar/actions) 为准。本机构建不等于新的 Android 真机验收。固定工具链仍有面向未来 Gradle 10 的弃用提示。

| GitHub Source code | 源码；需要自备 Python/.NET 或 Android 构建环境 |

Windows 包包含 Python、时区数据和 .NET，以及两款内置日历和三个预装插件，共五款游戏。更新前从托盘“退出游时”、创建备份并另存旧 `data/`，然后解压到新目录迁移数据，避免用新包初始数据覆盖个人记录。

更新软件不会自动重写现有活动缓存。若卡池仍显示旧截止，请在来源允许请求时手动同步明日方舟，确认相关官方公告成功读取；若标有“已手动校正”，请核对并按需恢复公告时间。仍遵守站点冷却与限流，不反复点击重试。

Android 覆盖安装要求相同签名。签名不一致时不要直接卸载有个人数据的旧版；卸载或清除数据会删除个人记录。本次 APK 是调试测试包，尚未作为商店正式发行。

## 已知边界

- 本机网页/Windows 服务信任当前操作系统用户，不能直接代理到公网；读取没有独立账户登录。见 [安全边界](../../SECURITY.md)。
- Android 真机、软键盘、系统栏和旧 WebView 的新版本验收仍待完成；移动端完整规划和撤销契约仍按待办推进。
- 提醒依赖本机程序与系统通知；不直接向 Windows 时钟面板注入日历。
- 数据与提醒可能有误，免责声明不保证绝对免责，活动情况以游戏官方最新公告为准。素材与来源许可见 [NOTICE](../../NOTICE.md) 和[开发文档](../development.md)。
