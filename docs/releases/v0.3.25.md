# V0.3.25 · 网页任务往返、安卓测试外壳与安全加固

日期：2026-11-13。此版本整合网页 C1/C2、共享接口、安卓外壳和本轮审计修改。插件 API 1 与既有个人数据格式继续兼容，不包含个人数据库、缓存或日志。

## 本版变化

- 当天截止汇总 → 活动详情 → 个人计划可逐层返回，恢复焦点与滚动；关闭、Esc、浏览器后退统一处理未保存草稿。
- 计划保存后按来源返回，失败保留输入，重试创建不重复；临时定位后可回到原游戏、视图和筛选。主题与布局独立保存。
- 月历日期格按截止密度填充，右下角显示数量；点击查看当天截止明细，统一主题填充色，今天用横线标记。
- 安卓专用近期、日历、计划与我的页面，复用共享数据与嵌入时间轴，提供触控和系统字体/主题适配。仍是测试版。
- 修复异常 token、URL、JSON 和含糊 HTTP 正文处理，增加读取超时及跨站来源校验；日志脱敏和轮转；Android 解包中断后可重试。
- 补齐 CI 矩阵、依赖锁、下载校验和打包前资源完整性检查。详细验证与限制见 [安全兼容审计](../security-compatibility-audit-2026-11-13.md)。

## 升级

1. 从旧版托盘选择“退出游时”，在设置中创建备份，并另存整个旧 `data/`。
2. 新版完整解压到新目录，再迁移旧数据，保留数据库、窗口设置和自定义插件；不要用新包的初始文件覆盖旧数据。
3. 运行新版，核对个人标记、计划、游戏组合及提醒范围。手动同步仍遵守来源冷却和限流。

Android 覆盖安装要求签名一致；若签名不一致，不要为升级直接卸载有个人数据的旧版。测试版导出尚不完整，应先确认可保留数据再处理。卸载/清除应用数据会删除个人记录。

## 已知边界

- 普通网页/Windows 服务只监听本机，信任当前系统用户；读 API 没有独立登录，不可公开代理到公网。见 [SECURITY](../../SECURITY.md)。
- 计划删除的完整恢复 ID/关联契约仍待实现；安卓重新创建式撤销不是完整恢复保证。
- APK 为调试测试包，不是应用商店正式签名包；新构建的真机、软键盘、低版本 WebView 和系统栏验证仍待完成。历史模拟器结果不等于新版本真机验收。
- 原生桌面通知需要程序运行；Windows 时钟面板由系统管理，本项目不直接注入其日历。
- 公开资料可能因源站和网络延迟缺失；活动情况及时间以游戏官方为准。
