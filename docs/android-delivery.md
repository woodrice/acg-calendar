# 游时 安卓测试版交付说明（M3）

本文记录安卓测试 APK 的构建、安装、已验证项和已知限制。接口约定见 [安卓外壳接口](android-shell-source.md)，界面方案见 [安卓应用 UX 方案](android-app-ux-proposal.md)。

## V0.3.25 发布批次

本版将安卓外壳与共享 C0/C2、网页续作和安全修复纳入同一源码树，版本 0.3.25 / versionCode 325。新包校验值以发布页的 `SHA256SUMS.txt` 为准；下面的 V0.2.7 文件和设备结果作为历史记录保留，不用于证明本版已经完成真机验收。

新 APK 仍为调试签名，仅用于受控侧载测试；导出、后台常驻/系统通知、完整计划删除撤销和真机键盘验证的限制继续存在。Windows 是本版主要桌面发行包，下载与升级见 [V0.3.25](releases/v0.3.25.md)。

## 构建

需要 JDK 17、Android SDK（`D:\Android\sdk`）和 Gradle 缓存目录：

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot'
$env:GRADLE_USER_HOME='D:\Android\gradle-home'
cd android
.\gradlew.bat assembleArm64Debug assembleX86_64Debug --no-daemon
```

构建时 `stagePlaytime` 把 `app.py`、`acg_calendar`、`web`、`rules`、`samples`、`plugins` 和时区数据打包进 APK，并写入新的 `BUILD_STAMP`。应用启动时发现 `BUILD_STAMP` 变化，就重新解出这些文件，个人数据目录不动。

## 安装与升级

- **首次安装**：把 APK 拷到手机，用文件管理器打开安装（需要允许「安装未知应用」），或者 `adb install <apk>`。
- **升级**：直接覆盖安装新 APK，或 `adb install -r <apk>`。收藏、完成、个人计划、游戏组合和配色预设保存在本机数据库，覆盖安装后保留。版本号相同时也可以覆盖安装，前提是签名一致（同一台机器构建的调试包）。
- **深浅模式**（跟随系统／浅色／深色）保存在页面存储里，按页面地址区分。本地服务每次启动沿用上次的端口，地址不变，选择就会保留。如果那个端口恰好被别的应用占用，会换一个端口，这一项回到「跟随系统」。改完一两秒内强行结束应用，也可能来不及写入。从没有记录端口的旧包（例如 11 月 6 日首版）第一次升级时，也会回到「跟随系统」，之后保持。
- **卸载或清除应用数据**会删除全部个人记录。测试版不能导出备份。

## 未验证

- 本轮新 ARM64 包没有上真机；真机只测过较早的 ARM64 包（Android 7–12）。
- 输入法弹出时页面缩到键盘上方（Android 15 全面屏），MuMu 键盘不占屏幕空间，测不了。
- Android 7.0/7.1 的导航栏：浅色主题下导航栏改为黑底（这两版没有深色导航按钮），没有设备实测。
- Android 13–14 真机、平板和横屏、真实手势导航栏、刘海屏。
- 系统大字号和分屏。
- 一次真实联网同步：本轮按限流要求没有在设备上触发联网同步。手动同步在第三十三节的首版上验证过。

## 已知限制

- **删除计划的撤销**：撤销按「尽力恢复主体」实现，恢复后计划 ID 会变。删除后关联失效时，失效的关联会被去掉；关联游戏已卸载的计划删除前要先确认且不能撤销。如果编辑面板打开期间计划被别处改过、而页面还没收到更新，撤销可能恢复改动前的内容（例如旧备注）。完整恢复要等 Codex 提供服务端恢复凭证（第三十六节）。
- **联网暂停**：手机上不能暂停或恢复联网；暂停时同步按钮不可用。
- **备份、导出、系统通知**：测试版都不支持。
- 应用内选「浅色」或「深色」与系统不同时，状态栏和导航栏颜色跟随应用，启动瞬间的窗口底色仍跟随系统。
- 系统切换深浅色时不重建页面（这样不会丢正在填写的内容），所以启动提示页和窗口底色要到下次启动才跟上。
